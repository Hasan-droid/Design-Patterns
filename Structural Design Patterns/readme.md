# Structural Design Patterns

`Design patterns that help Structure Classes and Objects in order to decouple different components in way that change can be made to one component would not effects the other components`

| Design Pattern           | Purpose                                                            |
| ------------------------ | ------------------------------------------------------------------ |
| Adapter Design Pattern   | allows classes with incompatible interfaces to work together       |
| Bridge Design Pattern    | Decouples Abstraction from its Implementation                      |
| Composite Design Pattern | Defines a group of objects treated as single object                |
| Decorator Design Pattern | Adds new functionality to existing object with alter its structure |
| Facade Design Pattern    | Provides A Simplified Design Pattern To Complex subSystems         |
| FlyWeight Design Pattern | minimize memory use by sharing data with related object            |
| Proxy Design Pattern     | Provides a surrogate for another object to control access to it    |
